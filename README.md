# Юрский берег — 3D-анимация

Процедурная кинематографичная 3D-сцена на Three.js (один файл, без сборки).

- Динозавры — скелетные модели (SkinnedMesh) из гладких сплайновых трубок с процедурными текстурами кожи; тираннозавр, три велоцираптора, теризинозавр с перьевым покровом.
- Процедурная анимация: бег/шаг с фазами ног, обгладывание туши, тревога, бегство, рёв с замахом и дрожью.
- Окружение: рельеф с текстурой, река с отражениями, камни, трава на ветру, папоротники, саговники, хвощи, сосны и араукарии.
- Закатное освещение: низкое тёплое солнце с мягкими тенями, контровой свет, небо с облаками, окружающее освещение от неба, пыль в воздухе, bloom, виньетка и зерно.

Запуск: откройте `index.html` через любой статический сервер, например `python3 -m http.server 8000`, и перейдите на http://localhost:8000/index.html. Three.js подгружается с CDN, нужен доступ в интернет и видеокарта с WebGL2.

Анимация длится 36 секунд и зацикливается; кнопка «Сначала» перезапускает её.

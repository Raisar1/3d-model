# Юрский берег — 3D-анимация

Процедурная 3D-сцена на Three.js (один файл, без сборки).

Запуск: откройте `index.html` через любой статический сервер, например `python3 -m http.server 8000`, и перейдите на http://localhost:8000/index.html. Модули Three.js подгружаются с CDN, нужен доступ в интернет.

Анимация длится 30 секунд и зацикливается; кнопка «Сначала» перезапускает её.
